## 題材と品質確認

具体プロンプトと初回の実践検証には、Go＋Wails v2 のメモ管理デスクトップアプリを使います。メモの登録・編集・検索・タグ・保存を扱います。確定事項と残件は[想定アプリケーション](../authoring/example-application.md)を参照してください。

新規作成版の品質は、内容のレビューと、掲載した具体プロンプトを Codex に実際に入力して題材アプリを作成・リリースする実践検証で確認します。最初に共通本編と Go＋Wails v2 の経路を検証し、その結果を残りの補足資料へ反映します。

執筆・文書レビューの状況と、技術構成・OS・CPU ごとの動作確認状況は分けて記録します。検証範囲と既存アプリケーションの改修版への着手判定は、[作成方針の品質確認](../authoring/creation-policy.md#14-作成と品質確認の進め方)に従います。
